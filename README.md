para correr a aplicação deves por o comando no terminal bash dentro da pasta cliente:
 npm install
 npm run dev
e abrir http://localhost:5173
**Express (3000):** HTML feito no **servidor** → View Source mostra tudo.

**React (5173):** HTML feito no **browser** → View Source mostra só `<div id="root">`.

**Prova:** View Source ≠ Elements ⇒ foi feito no cliente.
